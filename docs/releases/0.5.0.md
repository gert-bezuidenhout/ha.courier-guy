## Changes

- Explicit Location, Collection Hub and Delivery Hub labels on each shipment.
- Bundles the dashboard module and logo inside the integration for HACS delivery.
- Registers the frontend module automatically and versions its URL from the integration release. No manual Resources changes or separate dashboard file copies are needed.
- Adds a live card preview in the dashboard card selector.
- Supports a blank-reference Dashboard entry for first-time setup before adding parcels from the card.
- Preserves existing card configurations and tracking entries. Older manual resource URLs can remain configured.

## Update

Update through HACS, restart Home Assistant, then refresh your browser or Companion app. No dashboard resource URL edits are required. Existing tracking notifications from 0.4.0 remain supported.

New users: add The Courier Guy / PUDO in Devices & services and leave the tracking reference blank to activate the dashboard, or enter a waybill. Then choose The Courier Guy / PUDO from the dashboard card selector.
